# 算法题解库 · Algorithm Problem Solution Website

面向程序设计课程学习与复习的静态题解网站，整理 XMUOJ「2026 年程序设计实践例题（05 李胜睿班）」相关题目，提供题目浏览、算法分类、题解阅读和本地内容管理功能。

项目使用 HTML、CSS 和原生 JavaScript 开发，无需安装前端依赖或执行构建命令，也无需后端数据库。当前 `data.json` 收录 76 道题目，支持 C++ 和 Python 题解字段，部分题目暂未提供 Python 内容。

![网站首页封面](assets/cover-tokusatsu-01.webp)

## 功能介绍

- **题目浏览**：以卡片展示题目，按算法标签、题库筛选，搜索题目名称、标签或 C++ 题解内容。
- **难度排序**：按低、中、高排序，未标记难度的题目排在后面。
- **题解阅读**：查看原题描述，切换 C++ / Python 题解与代码，支持代码高亮和一键复制。
- **内容排版**：支持基础 Markdown 语法，以及 `$...$` 行内公式和 `$$...$$` 独立公式。
- **题目管理**：通过管理页面添加、编辑、删除题目，编辑时可预览题目描述和题解。
- **标签与题库**：添加自定义算法标签，创建题库并批量维护题库中的题目。
- **数据备份**：导出 JSON，或导入已有备份进行合并、替换。

## 本地运行

准备现代浏览器，并在项目根目录启动一个静态 HTTP 服务。例如，已安装 Python 3 时运行：

```bash
python -m http.server 8000
```

Windows 也可以使用：

```powershell
py -m http.server 8000
```

然后访问：

- 首页：<http://localhost:8000/>
- 管理页面：<http://localhost:8000/admin.html>

也可以使用编辑器的静态服务器插件。建议通过 HTTP 服务访问；直接双击 HTML 文件可能导致 `fetch('data.json')` 读取失败，页面转而加载内置默认数据。

代码高亮、数学公式和字体资源通过 CDN 加载，完整显示效果需要能够访问对应网络资源。

## 使用与内容维护

### 浏览题解

1. 在首页选择算法标签或题库，也可以输入关键词搜索。
2. 点击题目打开详情，阅读原题、算法思路和代码。
3. 根据需要切换语言、复制代码，或通过编辑入口进入管理页面。

网站用于展示和整理题解，不提供在线编译、运行或判题功能。

### 管理题目

点击首页的「管理」按钮，输入管理密码后进入后台。添加题目时，题目名称、至少一个算法标签、C++ 题解和 C++ 代码为必填项；原题描述、难度和 Python 内容等可按需填写。

管理密码的 SHA-256 摘要配置在 [`js/auth.js`](js/auth.js) 的 `PASSWORD_HASH` 常量中，登录状态保存在当前会话的 `sessionStorage`。仓库未提供明文密码；如需设置自己的密码，可在本地网站的浏览器开发者工具控制台运行：

```javascript
await sha256('替换为你自己的管理密码')
```

将返回的摘要写入 `PASSWORD_HASH` 并刷新页面。密码校验依赖 Web Crypto API，本地使用 `localhost`，部署时使用 HTTPS。

这里的密码校验仅控制前端管理入口，不构成服务端权限验证。所有题解数据和前端代码均可被访问者读取。

### 数据保存与备份

后台保存的修改写入当前浏览器、当前站点的 `localStorage`，**不会直接修改仓库中的 `data.json`，也不会自动同步到其他设备或访问者**。更换浏览器、域名或端口后，本地数据也不会自动共享。

初始化时按以下顺序加载题目：

1. 浏览器中有效且非空的本地题目数据。
2. 根目录的 `data.json`，读取成功后缓存到本地。
3. `js/defaultProblems.js` 中的内置默认题目。

后台点击「导出数据」可下载包含题目、自定义标签和题库的 JSON 备份。导入时，当前确认框的行为是：

- 点击「确定」：按 `id` 合并，已有的同 ID 题目或题库会被更新。
- 点击「取消」：替换题目列表，**并非中止导入**；导入文件中非空的标签和题库列表也会覆盖对应数据，空列表则保留本地原值。

导入前建议先导出备份。浏览器清理站点数据后，本地修改可能丢失。

### 发布更新

1. 在后台完成编辑并导出数据。
2. 将导出的 JSON 文件重命名为 `data.json`，替换项目根目录的同名文件。
3. 将更新后的项目文件上传到静态网站托管服务，保持目录结构不变，无需构建。
4. 使用没有该站点本地缓存的浏览器环境验证新数据。

已有访问者的本地数据优先于站点的 `data.json`，因此仅刷新页面不一定能看到新版题库。需要先备份本地修改，再清除该站点相关的本地存储并刷新，或通过后台导入新版 JSON。

## 项目结构

```text
.
├── index.html              # 首页：筛选、搜索、题解详情
├── admin.html              # 管理页面：题目、标签、题库与数据导入导出
├── data.json               # 部署站点的静态题库数据
├── README.md               # 项目说明
├── css/
│   └── style.css           # 页面样式与响应式布局
├── js/
│   ├── data.js             # 数据加载、本地存储、标签/题库操作与公式工具
│   ├── defaultProblems.js  # 加载失败时使用的内置默认题目
│   ├── auth.js             # 管理密码校验与会话状态
│   ├── main.js             # 首页交互与题解渲染
│   └── admin.js            # 后台编辑、预览与导入导出
└── assets/                 # 首页与管理页面封面图片
```

## 数据格式

推荐使用包含以下三个字段的 JSON 对象；加载与导入也兼容旧版的纯题目数组。

```json
{
  "problems": [
    {
      "id": 1,
      "title": "示例题目",
      "tags": ["入门"],
      "difficulty": "低",
      "source": "题目来源",
      "original_problem": "## 题目描述\n在这里填写题意。",
      "explanation_cpp": "## 算法思路\n在这里填写 C++ 题解。",
      "code_cpp": "// 在这里填写 C++ 代码",
      "explanation_python": "",
      "code_python": ""
    }
  ],
  "customTags": [],
  "collections": [
    {
      "id": 1,
      "name": "示例题库",
      "description": "题库说明",
      "problemIds": [1]
    }
  ]
}
```

题目和题库各自使用唯一的数值 `id`，题库通过 `problemIds` 引用题目。难度可填写 `低`、`中`、`高` 或空字符串；后台会在添加、更新时自动记录相应时间字段。

## 技术组成

| 技术 | 用途 |
| --- | --- |
| HTML / CSS / 原生 JavaScript | 页面结构、样式与交互 |
| localStorage / sessionStorage | 本地题库保存与管理会话状态 |
| Highlight.js 11.9.0 | 代码语法高亮 |
| KaTeX 0.16.9 | 数学公式渲染 |
| Noto Sans SC / JetBrains Mono | 中文与等宽代码字体 |

Markdown 内容由项目中的自定义渲染函数处理，支持的语法以页面实际效果为准。
